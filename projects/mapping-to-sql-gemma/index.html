Summary
Situation

Banking and enterprise migration teams spent days manually coding multi-table SQL queries from messy analyst Excel mapping sheets, while strict privacy rules banned sending schemas to external cloud APIs.

Task

Build an on-premise tool that lets analysts upload mapping sheets and generate valid ANSI SQL inside JSON on existing single-GPU hardware without external cloud calls.

Action

Benchmarked Google Gemma 2B on 50 samples, upgraded to Mistral-7B-Instruct-v0.3 on 900 pairs with 8-bit quantized LoRA (r=8, alpha=16) under 8.5 GB VRAM, added pre-inference mapping rule normalization and join-key inference, and deployed an on-premise self-service web portal.

Result

Replaced slow manual query writing with a local self-serve upload workflow, dropped training loss from 1.049 to 0.184 (min 0.173 at step 500), and handed over model weights and setup documentation via live walkthrough.

Business Workflow & On-Premise Need

During banking data warehouse migrations, business analysts document source-to-target rules in Excel and CSV spreadsheets, leaving data engineers with days of repetitive SQL translation. Because strict financial privacy policies prohibited sending proprietary table schemas to cloud LLM APIs, the client needed a self-serve application running completely inside their own environment on modest GPU hardware (8.5 GB VRAM).

Iterative Model Adaptation & Pre-Inference Normalization

After benchmarking Google Gemma 2B on 50 initial samples showed struggles with long multi-table joins, the system was upgraded and delivered using:

  • 8-Bit Quantized LoRA Adaptation: Fine-tuned Mistral-7B-Instruct-v0.3 on 900 JSONL mapping-to-SQL pairs (rank r=8, alpha=16 on attention projections) via Hugging Face SFTTrainer within an 8.5 GB peak VRAM budget (T4 / RTX 3090).
  • Pre-Inference Mapping & Join Normalization: Standardizes informal analyst transformation shorthand into canonical SQL expressions and automatically infers missing foreign-key join relationships from table schemas before inference.
  • Dialect-Safe JSON Output: Generates structured JSON wrapping ANSI SQL with INNER, LEFT, and FULL/RIGHT OUTER joins, COALESCE null-fallback logic, and deterministic table aliasing.

Self-Serve Delivery, Handover & Demo

Deployment and client enablement highlights:

  • On-Premise Self-Service Web Portal: Delivered a browser-based FastAPI upload portal where analysts drop in Excel/CSV mapping workbooks, inspect generated SQL and JSON manifests, and export production queries with zero external cloud exposure.
  • Verified Convergence: Cross-entropy loss decreased from 1.049 (step 10) to 0.184 (step 700), with a minimum of 0.173 at step 500.
  • Live Handover: Ran a live walkthrough demonstrating upload-to-SQL workflows and delivered weights, source repository, and setup runbooks to the client team.
  • Interactive Demo: Inspect loss curves, sample SQL outputs, and pre-inference rule normalization in the Interactive SQL Fine-Tuning Demo.
