Summary
Situation

Enterprise migrations require converting messy source-to-target mapping sheets into SQL. Off-the-shelf models repeatedly hallucinated join aliases and failed to handle null-fallback expressions.

Task

Fine-tune an open-source, air-gappable foundation model on 900 enterprise mapping pairs to synthesize deterministic ANSI SQL with consistent schema structure and zero cloud data leaks.

Action

Evaluated Google Gemma 2B baseline before adapting Mistral-7B-Instruct-v0.3 with 8-bit quantized LoRA (r=8, alpha=16); built an automated typo-healing preprocessor; served via Python API.

Result

Training loss dropped from 1.049 to 0.184 over 700 steps (minimum 0.173 at step 500); verified syntactically valid ANSI SQL across client test datasets; delivered valuation report with sign-off.

System Overview & Privacy-Constrained Scope

Enterprise data warehouse modernizations require converting business analyst mapping workbooks into production SQL queries. Because financial and regulatory policies strictly prohibit sending proprietary banking schemas to multi-tenant cloud APIs, the objective was building a self-contained, air-gappable neural compiler running on modest commodity GPUs (8.5 GB VRAM budget) for deterministic ANSI SQL synthesis.

Quantized LoRA Adaptation & Preprocessing

Base foundation models failed to resolve complex joins or suffered prompt truncation. The fine-tuning and preprocessing pipeline was engineered with:

  • 8-Bit Quantized LoRA: Adapted Mistral-7B-Instruct-v0.3 using bitsandbytes and Hugging Face SFTTrainer (rank r=8, alpha=16) targeting attention projections (q_proj, k_proj, v_proj, o_proj) within 8.5 GB peak VRAM.
  • Dataset Curation: Built 900 verified enterprise mapping-to-SQL JSONL pairs enforcing explicit table-column relationship prompts.
  • Heuristic Typo Resilience: Pre-tokenization normalization algorithm resolving common analyst misspellings (e.g. COLEASE to COALESCE, LOWWER to LOWER) and inferring required foreign keys from join conditions.

System Architecture, Evaluation & Demo

Production engineering and verification highlights:

  • Local API Serving: Packaged a FastAPI service with a local web UI so the client could evaluate generations without sending schemas to a multi-tenant cloud API.
  • Loss Convergence: Training cross-entropy loss decreased from 1.049 at step 10 to 0.184 at step 700 (minimum 0.173 at step 500) without general syntax degradation.
  • Dialect & Join Verification: Checked syntactic validity across client test sets, including sequential alias projection (t1..tN).
  • Interactive Demo: Inspect training loss curves, compare base vs. fine-tuned SQL generation, and test typo normalization in the Interactive SQL Fine-Tuning Demo.
