Multimodal Quiz Generation SaaS

A full-stack assessment product that turns text, documents, and diagrams into editable quizzes with multiple question formats and export options.

FocusMultimodal ingestion, AI-assisted content generation, product workflows, and SaaS architecture.
Core TechnologiesFastAPI · React · OpenAI · MySQL
Project TypeLLM applications
Summary
Situation

Educators and corporate trainers spend dozens of hours manually authoring quizzes and assessments from textbooks, PDFs, and hand-drawn lecture whiteboards.

Task

Architect an end-to-end full-stack SaaS platform capable of multimodal ingestion (text, PDFs, diagrams) to generate standardized interactive quizzes across 4 question formats.

Action

Sole developer of FastAPI + React/TypeScript platform; integrated OpenAI GPT-4 and Vision API; implemented JWT auth with token rotation, Zustand practice state, and PDF/JSON exporters.

Result

Shipped a working SaaS prototype with weekly usage quotas, four question formats, an interactive editor, and Docker Compose for MySQL.

Platform Overview & Scope

Architected and built the full-stack software system—from the FastAPI microservices to the React/TypeScript frontend—for an AI-powered educational SaaS platform. The product allows educators, students, and corporate trainers to convert diverse study materials into interactive assessment quizzes across multiple formats.

Multimodal Document & Vision Ingestion

The platform accepts three distinct input modalities, each parsed with dedicated pipelines:

  • Direct Raw Text: Paste notes, lecture outlines, or articles for prompt synthesis.
  • Smart PDF Processing: Custom document parsing extracting clean text while preserving paragraph structure, tables, and section hierarchies.
  • OpenAI Vision Integration: Ingests uploaded diagrams, lecture whiteboards, textbook screenshots, and handwritten notes to extract visual concepts into question stems.

Supports 4 distinct assessment formats: Multiple Choice Questions (MCQ), True/False, Fill in the Blanks, and Matching pairs.

Full-Stack SaaS Architecture & State Management

Key full-stack engineering features include:

  • Authentication & Security: JWT-based authentication with access and refresh tokens, automatic token rotation, and bcrypt password encryption.
  • Usage Quotas & Subscription Tiers: Database-backed rate limits tracking weekly generation counts for free users with upgrade triggers for pro accounts.
  • Interactive Quiz Editor & Practice Mode: React + Zustand state engine allowing users to take quizzes interactively with instant scoring feedback or edit questions before export.
  • Multi-Format Exporters: Programmatic export to styled PDF, JSON schemas, or plain text.
  • Containerized Infrastructure: Docker Compose running MySQL 8.0 with utf8mb4 character sets and SQLAlchemy ORM migrations.
