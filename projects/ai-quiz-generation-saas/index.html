Quizentia — AI Quiz & Assessment Builder

Live EdTech SaaS (quizentia.com) that turns PDFs, diagrams, YouTube videos, and web links into editable assessments across 4 question types—cutting hours of manual test writing down to seconds.

Focus5 multimodal content parsers, interactive editing and practice mode, multi-format export, and SaaS tier quotas.

Project TypeLLM applications
Summary
Situation

Educators, corporate trainers, and students spent hours manually drafting quiz questions and answer keys from scattered PDFs, handwritten whiteboard photos, YouTube lectures, and web articles.

Task

Build and ship a live self-serve SaaS platform supporting all 5 content formats, inline quiz editing, interactive practice, and clean exports with SaaS account tiers.

Action

Sole full-stack builder using FastAPI, 5 specialized ingestion parsers, OpenAI GPT-4o/Vision with Pydantic validation, MySQL 8.0 usage quotas, JWT cookie auth, SlowAPI rate limiting, and a React 19 + Tailwind CSS v4 frontend.

Result

Launched live at quizentia.com, compressing hours of manual quiz authoring into seconds across 5 input sources and 4 interactive exportable question formats.

Stakeholder Need & Live SaaS Product (quizentia.com)

Course creators and educators needed a single workspace to convert real study materials—multi-page textbooks, diagram screenshots, lecture videos, and online articles—directly into structured assessments without tedious copy-pasting. Live at quizentia.com, Quizentia handles ingestion, interactive practice, editing, and document export end to end.

5 Multimodal Ingestion Pipelines & 4 Question Formats

Dedicated FastAPI extraction pipelines normalize diverse learning sources before validated schema generation:

  • PDF Textbooks & Handouts: High-speed PyMuPDF document parsing that preserves paragraph structure and repairs line-break hyphenation across multi-page files.
  • Diagrams & Photos: OpenAI Vision API paired with EasyOCR and PyTesseract (supporting up to 5 images per upload) to parse slides, flowcharts, and handwritten notes.
  • YouTube Videos & Web Articles: Automated video transcript extraction plus headless Playwright and Trafilatura article parsing for dynamic web URLs and token-bounded text.
  • Structured Outputs: Enforces Pydantic validation to generate MCQ, True/False, Fill in the Blanks, and Matching Pairs.

Interactive Workspace & SaaS Infrastructure

Production engineering supporting real users and subscription limits:

  • Visual Editor, Practice & Export: React 19 + TypeScript + Tailwind CSS v4 + Zustand editor lets users modify/delete questions, run instant-graded Practice Mode, and export to PDF (jsPDF), JSON, or TXT.
  • SaaS Security & Metering: JWT access + HTTP-only refresh cookie rotation with bcrypt, free vs. paid weekly generation limits tracked in Dockerized MySQL 8.0, SlowAPI rate limits, and GeoLite2 analytics.
