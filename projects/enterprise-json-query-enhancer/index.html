Summary
Situation

During large enterprise migrations (e.g., merging banks, migrating to Snowflake), business analysts map legacy data fields to target schemas across dozens of messy Excel sheets.

Task

Data engineers traditionally spend 2 to 4 weeks manually handwriting thousands of lines of SQL joins, fallback rules, and pipeline DAG configs, causing human syntax errors.

Action

I built an AI generation engine that ingests the raw spreadsheet, automatically infers table join keys & aliases (t1...tN), converts business rules into ANSI SQL, and formats complete execution DAGs.

Result

Automated pipeline DAG manifest generation from spreadsheets, ensuring consistent schema structure and validating integration logic across test scenarios.

Platform Overview & Scope

Enterprise data warehouse migrations require orchestrating multi-stage Spark Directed Acyclic Graphs (DAGs) through structured JSON manifests. Designed and delivered during an intensive 6–8 day forward-deployed sprint, this compiler automates spreadsheet ingestion, schema extraction, and execution manifest synthesis with Google Gemini 2.0 Flash.

Multi-Stage Spark DAG Manifest Pipeline

The compiler translates complex tabular mapping rules into a deterministic 7-stage Spark execution sequence:

  • Date Partitioning (Flow 1): Extracts execution date parameters into isolated partition dataframes to prevent full-table scans.
  • Isolated Source Extractions (Flows 2..N+1): Emits parallel extraction queries for each unique source table with sequential dataframe aliases (t1..tN).
  • Unified SQL Integration (Flow N+2): Executes joined business transformations, fallback COALESCE expressions, and registers integration tables.
  • Target Persistence (Flow N+3): Registers target warehouse write-through partitions with automated partition overwrites.

Incremental Schema Patching, Validation & Demo

Production reliability and validation features:

  • Incremental Schema Enhancer: Core delta diffing algorithm that patches new source tables and attributes into existing live DAG manifests without rewriting tested upstream flows.
  • 10 Pre-Flight Verification Checks: Validates database connectivity, target table writeability, schema compatibility, and DAG dependency acyclicity before cluster execution.
  • Schema Hygiene & AST Validation: Isolates raw JSON array boundaries and enforces schema contracts for flow IDs, sequence dependencies, and register names.
  • Interactive Demo: Test full pipeline compilation and delta schema patching in the Interactive ETL DAG Compiler Demo.
