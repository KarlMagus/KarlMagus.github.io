Summary
Situation

Follow-up enterprise data migration teams spent 2 to 4 weeks manually writing multi-stage Apache Spark DAG JSON configs and risked breaking live pipelines whenever analysts added new columns or tables.

Task

Deliver a self-serve compiler that builds 7-stage Spark DAG manifests from spreadsheets and safely patches schema updates into existing DAG files.

Action

Built a Python/Flask service with Gemini Flash and Pandas to compile 7-stage DAG manifests, created an Incremental Schema Enhancer for delta patching, and added 10 pre-flight validation checks in a 6–8 day sprint.

Result

Automated pipeline configuration and schema evolution with zero manual JSON rewriting, walked the engineering team through the workflow on Google Meet, and handed over the repository and setup guide.

Stakeholder Problem & Rapid Sprint Scope

After automating single-query generation, the client's data engineers needed full multi-stage Apache Spark ETL orchestration configs—and a safe way to add newly requested tables without rewriting tested production JSON files by hand. Built and delivered in a focused 6–8 day sprint, this compiler turns analyst mapping spreadsheets directly into cluster-ready Spark DAG manifests.

7-Stage Spark DAG Workflow

Engineers upload mapping sheets via the web UI and receive a validated 7-stage Spark DAG manifest:

  • Stage 1 — Partition Scoping: Extracts execution date parameters to prevent costly full-table warehouse scans.
  • Stages 2–5 — Parallel Source Extraction: Generates isolated source extraction queries with deterministic dataframe aliasing across upstream tables.
  • Stage 6 — Unified Integration & Null-Safety SQL: Combines multi-table join transformations with standardized COALESCE fallback handling.
  • Stage 7 — Target Warehouse Persistence: Configures partitioned write-through loading into target data warehouse tables.

Incremental Schema Patching, Pre-Flight Safety & Handover

Operational safety checks and post-sprint handover:

  • Incremental Schema Enhancer: Automatically diffs newly added tables or attributes and patches them into existing DAG JSON manifests without modifying verified upstream flows.
  • 10 Automated Pre-Flight Checks: Verifies JSON schema structure, flow ID ordering, column references, DAG acyclicity, and path writeability before cluster deployment.
  • Walkthrough & Documentation: Conducted a live Google Meet walkthrough with the client team and delivered the codebase and operational setup guide.
  • Interactive Demo: Test pipeline compilation and delta patching in the Interactive ETL DAG Compiler Demo.
