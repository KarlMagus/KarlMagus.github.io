Summary
Situation

A client had inherited a third-party inventory/operations Canvas App that took ~9 seconds to load, missed older records behind silent delegation limits, and frustrated staff enough that they abandoned it for spreadsheets.

Task

Diagnose the root causes behind slow rendering and missing records, eliminate delegation issues, and restore a fast, reliable user experience without rebuilding from scratch unless necessary.

Action

Replaced full-list client filtering with delegable server-side Filter() on indexed SharePoint columns before local Search(), cached small static lookup lists once via Concurrent(ClearCollect(...)) instead of N+1 per-row LookUp() calls, removed redundant OnVisible reloads, reduced control bloat, and added explicit loading/error states.

Result

Dropped screen load time from ~9s to ~3s (~67% faster), reduced delegation warnings to zero, stopped silent row truncation, and brought daily staff adoption back into the app.

Root-Cause Audit of the Abandoned App

The legacy app failed users not because SharePoint could not handle the data, but because every screen load forced client memory to pull and recalculate too much at once:

  • Ignored Delegation Warnings: Non-delegable Search(AddColumns(...)) formulas silently capped SharePoint results at 500 rows and hid older inventory items.
  • N+1 Per-Row Network Calls: Each rendered gallery card fired repeated LookUp() queries against Departments and Employees.
  • Bloated OnVisible & Controls: Navigation triggered redundant data refreshes and rendered secondary admin tables upfront without loading indicators.

Delegation-Safe Power Fx & Caching Refactor

Targeted Power Fx changes delivered immediate speed and data completeness gains:

  • Server-Side Filter() First: Wrapped indexed equality/date filters (Status, Created) inside a With() block pushed to SharePoint before running text search on the small returned slice.
  • One-Time Lookup Caching: Loaded static reference tables once at startup using Concurrent(ClearCollect(...)) so gallery labels resolve from RAM in under a millisecond.
  • Lean Screens & Explicit States: Trimmed control count, deferred secondary panels until selected, and added clean loading spinners plus user-friendly error banners.

Verified Impact & Before/After Code Simulator

Deployed cleanly through Dev → Test → Prod Managed Solutions with column-change safety checks:
